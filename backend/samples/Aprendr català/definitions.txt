  Definition of step:
    - a question asked to the user
    - it has one expected answer
    - it allows for multiple user attempts (3 by default)
    - a step is done when either the user answered correctly to the question or there are no more attempts available
  
  Definition of exercise:
    - it is a sequence of steps all of the same format inside the same exercise
    - the number of steps is 3 by default
    - it has one goal
    - an exercise is done when all steps have been done.

  Definition of unit:
    - a set of exercises focusing on a topic.
    - the unit is intended to practice subjuntive present tense.
